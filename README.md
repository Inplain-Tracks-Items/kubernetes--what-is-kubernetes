# What is Kubernetes

An introduction to Kubernetes and its role in production AI and Forward Deployed Engineering systems.

Part of the **Kubernetes** track on Inkplain Knowledge.

## How this repository works

Every step of the lesson has its own branch, and each one contains all steps up to it:

```bash
git clone https://github.com/Inplain-Tracks-Items/kubernetes--what-is-kubernetes.git
cd kubernetes--what-is-kubernetes
git branch -r            # list the step branches
git checkout step-01-…   # code after step 1
```

`main` holds the final, complete version.
